astlogic

View on GitHub ↗

Mentored research (CSC 498) · 13 rubric checks on 3 assignments

Checks the structure of Python programs against rubrics written in Prolog, without running the code. Output-based graders can be satisfied by hard-coded answers, so this asks whether a program uses the structures the assignment is about. Python's AST is translated into Prolog terms, and each rubric rule reports pass or fail with a matching exit code. I wrote the accompanying research paper under Dr. Mark F. Russo, where all 13 structural checks pass across three course assignments.

AccessGuard

View on GitHub ↗

103 tests · SQLite and PostgreSQL in CI

An access governance service. It finds people whose combined roles break a separation of duties rule, refuses a risky grant before it happens, and keeps a hash-chained audit log that shows if a record was altered. Open conflicts are reported as risk-rated exceptions mapped to NIST SP 800-53 controls, with a dashboard that opens on a plain-language summary.

logsentry

View on GitHub ↗

12 detection rules · scored on 13 planted attacks

Reads web server and SSH logs, detects attacks, and groups alerts into one incident per attacker. It then grades itself against labelled attack campaigns and look-alike harmless traffic, so you can see what it catches and what it misses. Lines that fail to parse are stored, not dropped. Standard library only, with SQLite storage and an HTML report.

Capital Bikeshare analysis

View on GitHub ↗

6.4 million trips · 12 months of public data

A SQL and pandas analysis of a year of D.C. bikeshare trips. Cleaning rules live in SQL and every rejected row is kept with its reason. It shows commute-shaped demand for members, a 2.7 to 1 swing between summer and winter, and which stations drain or fill on weekday mornings. Tested against an independent Python calculation, with the limits of the data written up.
